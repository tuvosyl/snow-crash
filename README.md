# 42 Snowcrash

## Overview

**Snowcrash** is a security-based project from **42 School** that challenges students with a series of escalating privilege escalation exercises. Each level presents a new vulnerability that must be exploited to gain access to the next level.

## Getting Started

### Prerequisites

- A **Linux-based** virtual machine (recommended: Debian or Ubuntu)
- Basic knowledge of **Unix commands** and **bash scripting**
- Understanding of **permissions, SUID and environment variables**


## Levels & Solutions

Each level introduces a specific vulnerability that must be exploited to obtain the next user’s credentials. Below is an overview:

- **Level 00 → Level 01**: Exploiting world-readable files
- **Level 01 → Level 02**: Taking advantage of an old password management system in /etc/passwd
- **Level 02 → Level 03**: learn to read pcap file and exploit them
- **Level 03 → Level 04**: Reverse engineer exploit
- **Level 04 → Level 05**: exploit a bad written perl script 
- ... *(More levels follow similar patterns)*

Each level solution is documented with a detailed explanation of the vulnerability and exploitation steps.
